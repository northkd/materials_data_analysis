# 本材冻结方法

真实输入限Oxyfluoride中括号式同配方两个目录：29/mp-1248208、48/mp-705559；各自aimd_1200K独立运行，relax仅作结构/启动关系。每条Na24 Ca24 Zr16 Si32 O120 F24，共240原子，展开式8倍。原件只读，结果按mp-id分目录。

## 时间、温度和MSD

两次流式核全1000预期保存帧，以真实configuration整数与POTIM建立绝对时间；NBLOCK只作交叉核验，不从20ps标题倒填。首保存configuration10，若末10000且步差10，则绝对0.02至20ps、跨度19.98ps，共同0–20ps只覆盖19.98ps。OSZICAR逐步核单调/重启/启动温峰，relax不当独立MD。

原图已实际看，图例只配方故必须通过工作簿列标29/48认mp-id。工作簿cell、两个旧CSV和原分析脚本口径分别记录；首原点、多原点、滞后时间、绝对时间、0/2/4ps剔除、固定4–14ps、后10/15ps重新起点并列。滞后末端原点数量保留，R²/斜率/6和幂指数只作有限窗诊断，不生成室温电导或活化能。

## 几何、Na与宿主

复用已读NaAl分析原语与旧mech_core事件筛选，SHA绑定且只读；本材元素/索引/阈值不沿用。r=f@cell，最短像由完整倒格界整数枚举证明，保存最大步位移与半最短晶格充分界。首原点、后段独立起点的端点/r90/最大探索/保存步累计路程/离返分别给出。离开>1Å再返回<0.5Å，1.5/1Å敏感性，未返右删失。全非Na等权平移为主，原始/宿主质量加权/全原子等权及宿主刚体配准为参考敏感性；转动/形变与局部固定配体运动分开。

1.5Å/200fs/直度≥0.7筛选、重叠合并、事后200fs单点和800fs内反向对消沿冻结原语；1.2/1.8Å敏感性。每Na的全部事件±200fs闭禁区排除，对照前/本体/后完整相位均排除。100/200/400fs同档中心、散布、首次返回/随访分别保存，缺200fs不借其他档。规则片段数不是晶格跳跃数。固定事件前6个O/F配体atom ID连续跟踪、仅平移参考及刚体转角/形变残差并列。

## 全部阳离子、配体和真实连接

Na/Ca/Zr/Si每保存帧分别O/F/混合CN、±0.1Å阈值、配体atom+image、距离/角度/径向畸变/身份保持。初始短壳逐中心冻结：Na/Ca候选4–16末邻≤4Å；Zr候选3–12末邻≤3.25Å；Si候选3–8末邻≤2.6Å；最大相对间隙，中点与末邻+0.2Å取小值，gap≤1.15明确无清晰壳。固定参考/次级层分别Na3.2/3.5Å、Ca3.2/4Å、Zr2.7/3.3Å、Si2.1/3Å。这些是几何切距而非价态/成键真值，短Si–F须凭距离/持续身份核，不能从O_IV标签推出。

Ca/Zr/Si固定初始配体ID每帧局部刚体拟合，保转动角、非刚性残差、中心偏移、初始配体保留和新邻居。每100fs全程及事件精帧真实连接：Zr/Si强中心、Ca/Zr/Si全部宿主中心、Na共享配体各图；完整宿主中心–O/F二分图；Na距离图3.5/4Å。保每边整数像/共享O/F，凸包顶点/真棱/支持面及中心异侧核几何，不以共享数直接命名共棱面。图像随原子整胞越界同步规范化，100/200fs持续过滤和±0.1Å敏感性；周期秩不当Na输运维度。

## 区域、空间、同式差异与改造

初始24个已占Na位置为有限参考，宿主平移、局部最近Zr/Si跟随参考两档，半径0.6/0.8/1Å；多候选歧义、不分配、非自身区域进入/≥200fs停留/下一去向/再离开均保存。不能由这24球报空位率/Frenkel浓度。Na数密度和每Na体积互为倒数，与12³分数网格全非Na统一1.2/1.5/1.8Å排除的几何开放比例/周期连通分开；每0.5ps采样，实际Na最近宿主间隙每帧对应，非能垒/自由能。

两个mp-id核CIF→MD逐元素映射、胞/Na布局、配位连接与启动差异，不从不同mp-id推出独立重复。无独立母结构/可靠位点全集时明确不足。B06只按实际已占位和证据给条件位置/补偿候选，不凭记忆选新元素，不新能量/动力学。C38四节报告、22 A/B/H、7 S、claim四级都附证据。
