# 本材方法与可判别问题

在真实数值前冻结。现有范围：O_I 精确 `(Na3Al2P2O8F3, mp-676467)` 的 `aimd_1200K`，静态 CIF/relax 只作映射和启动核验。全程每个保存帧分析（预计 1000 帧，实际以文件为准），不是五帧试算。

## 时间与 MSD

先两次流式读取核完整帧、整数 configuration、species/counts、POTIM 与 NBLOCK，再分配小型坐标数组。轨迹不复制。明确首保存帧的绝对时刻与首尾跨度；初始 POSCAR 只有结构无可替代轨迹，不能补成零时刻。OSZICAR 逐行抽 MD step/T/E，检查单调/重启和启动异常；relax/CONTCAR 与 MD POSCAR 分开核。

并列未校正、全非 Na 等权平移、全非 Na 质量加权平移、全部原子等权平移四参考。Na 真正运动诊断用全非 Na 等权参考；质量值写明来源为计算约定而非测量。另作宿主刚体配准（平移/转动）敏感性，形变残差不扣成迁移。

MSD 同时给首原点和多原点，0/2/4 ps 启动剔除、4–14 ps 固定生产窗和后段独立起点分列；逐项对比 XLSX 原 cell 与旧 CSV，不挑最接近口径。滞后 τ 的最大值仍须保留 n_origins。2–10 ps、短/长滞后分段线性拟合/α 只作有限窗诊断，斜率/6 不自动成为可靠 D，不算电导/室温或 Ea。

## 几何与个体运动

按 species/counts 展开真实 atom labels。r=f@cell，最短像用 reciprocal bound 完整整数枚举（对本材近正交胞可得到有限27像证书，不泛称任意胞27像充分）；解卷绕保每帧最大增量与充分采样界。真实端点、r90、max、保存步路径长分开。

离返沿已冻结原方法：离起点 >1 Å 后首次 <0.5 Å，末端未返右删失；另列1.5/1 Å敏感性。固定净位移1.5 Å/200 fs/直度≥0.7候选，重叠候选合并；200 fs事后单点标签、800 fs内反向抵消标签。继承只读 mech_core 函数并保 SHA。候选不当真实跳跃。阈值1.2/1.8 Å并列。

同Na对照：全部该Na事件（含当前）±200 fs闭禁区，控制前/事件/后完整相位均不相交；事件本身前后不足明记。固定事件前6个O/F配体ID追踪平移/转动/形变，200 fs和100/400 fs同档前后中心、首次返回、随访明列；缺200 fs不从其他档借。

## O/F环境与骨架

Na/Al/P每保存帧分别 O、F、混合配位，初始短壳由实际结构距离间隙冻结（Na候选4..12、Al/P候选3..8，末邻距离界与gap完整保存），±0.1 Å敏感性。另统一参考 Na 3.2 Å、Al/P 2.4 Å及次级到3.5/3.0 Å，避免自适应阈值掩盖异常。保每中心 ligand atom+image、距离、角度、径向畸变、初始/相邻身份保持。

Al/P固定初始配体ID逐帧局部刚体拟合与中心相对位移，分开旋转角、非刚性残差、初始配体保持和新邻居。CN不变不能证明单元稳定；转动和解体换邻居靠这些独立量区别。

每100 fs（全部时段）及事件前/中/后20 fs精帧存真实周期连接边：Al–P/Al–Al/P–P共享O/F，Na共享配体子网，完整非Na中心–配体二分图，Na距离图3.5/4.0 Å。共享数按双方凸包的实际顶点/棱/支持面验证，像平移用共享atom image差。阈值图与真实Na转移分开。

## 占据、布局与空间

以初始已占Na位置为有限参考，宿主平移、局部最近Al/P中心漂移跟踪参考并列，半径0.6/0.8/1.0 Å，多候选标歧义。完整≥200 fs停留须(end-start)dt≥.2；记录非自身区域进入/再离开/返回，周期像保留。不是位点全集，不报空位率/缺陷浓度。
