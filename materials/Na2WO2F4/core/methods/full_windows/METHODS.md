# Na₂W(OF₂)₂ 恢复方法与证据层

## 来源与时间

冻结成员 `families/O_VIII/MEMBERS.json` 对应 `64_Na2W(OF2)2_no-p-si-mp-505382`，原件绝对根 `[本机路径已移除]`。复用旧 S1 成功时标与输入SHA，见 REUSE_MANIFEST。1000帧、每20fs、绝对0.02至20.00ps，实际跨度19.98ps；不补零时刻、不把relax当独立MD。补充后处理读取此已有短轨迹，不运行新动力学。

六窗是全程、可用绝对0至20ps、绝对4ps起、绝对4至14ps、末10ps、末5ps。首原点/多原点MSD、raw/宿主等权去平移/全原子等权去平移分开；未引入未核验质量。真实温度与初始冲击按OSZICAR全步扫描，图的横轴与绝对MD时间分开。旧图3Å²线不是事件计数真值。

## 运动、事件、同Na环境

每个Na分别给端点、r90、最大离起点、保存采样折线路程、离开1Å/返回0.5Å和1.5Å/1Å敏感性，跨窗事件不是独立重复。宿主整体刚体拟合和固定W配体旋转/形变分开。

继承 `mech_core.detect_hop_events` 已读定义：每200fs候选位移≥1.5Å且直线度≥0.7；相邻候选按200fs间隔合并，合并后的net重新计算，因此可以小于1.5Å。旧 `persistent` 只检查完整随访的一个末点，不是连续停留。前后100/200/400fs中心与最宽可用窗分列。同Na全部合并事件±200fs闭区间禁区，控制窗连完整前中后相位全部不得相交；无档记missing。末点已回前区和后续真正观察返回分开。

Na与W是全部实际阳离子。每保存帧记录O/F壳、配体ID/周期像/距离/角度/径向畸变、壳±0.1Å、固定接触Na3.2Å/W2.5Å和短程以外至Na3.7Å/W3.2Å次级接触。初帧最大间隙壳是几何诊断，不是实测成键/价态。固定首壳ID的旋转/非刚体残差与持续接触、早中晚分段对应，不拿群平均代替个体同一时段。

## 周期图、候选区域与空间

0.1ps加末帧的周期图保留整数晶格像。W共享配体、完整非Na W/O/F二部图、Na共享配体与3.5/4Å距离图分列；共顶/棱/面做凸包和面两侧核查，低CN/退化几何不得强称共享面。100/200fs持久接触图是几何过滤，不是传导路径。

候选区域取首保存Na位置0.6/0.8/1.0Å球；全宿主等权去平移和邻近4W局部平移作为参考漂移敏感性。进入/离开/下个区域、200fs真实时间跨度及左右删失记录；这不是全部晶格位点，空位率null。每0.5ps加末帧12³周期网格，以1.2/1.5/1.8Å统一排除距离分别核宿主/全部原子空格；点格周期连通不提供连续低能路径或能垒。Na数密度与每Na体积互为倒数，不当两份独立机制。
