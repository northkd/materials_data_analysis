## 使用边界

归档没有独立方法MD，方法定义以最终REPORT为准。旧1001帧/严格1000帧、200fs/400fs及已披露无效对照分别解释。

1200 K单温短轨迹提供运动和环境对应证据。规则候选、参考球返回、几何连接和诊断斜率各有不同定义；科学独立接受状态为 `UNVERIFIED`。报告中的旧执行许可不适用于本公开包。原始轨迹、NPZ/NPY、生产源码及私人执行历史不包含在内。
