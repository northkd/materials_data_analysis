# 本材方法与判别问题

## 身份与范围

冻结O_I清单第18行、原图label与原仓精确目录共同定位 `(Na3Cr2P2O8F3, mp-720126)`。有界目录只见 `aimd_1200K/` 与 `relax/`；后者是结构优化而非额外1200K run。MD POSCAR实读 Na36 Cr24 P24 O96 F36，共216原子；12式量。POTIM=2fs、NBLOCK=10、NSW=10000、标称1200K。实际帧标记/时间/温度/重启由全程流式核，不拿名义20ps代替实际保存时长。原件只读，不复制轨迹。

## 复用与新适配

复用 `../Na3Al2P2O8F3/analyze_material.py`（SHA c2bbcf7f6cdfadef801d6aa583643f2f6bd8637c89a1351004b98f4e2314499e）和 `analysis_lib.py`（SHA 38da0601232a43a22ca3817f642ce18eef16ff5cfd4e2143955fe48976cc3118）。本树适配器先校SHA，再替换精确路径、formula/mp/session/注册文件、元素Cr与实际计数/质量计算约定。OUT与RES落本材，不写复用侧。旧Al数值不作为本材证据。质量51.9961amu只作固定质量参考约定；主要诊断用非Na等权参考。

新适配先RED暴露旧Al计数错误，再GREEN精确Cr断言；重放冻结30项合成回归（PBC/三斜/索引/全部事件禁区/完整相位/200fs暴露/旋转形变/同CN换配体/凸包棱面/参考漂移/多原点等），与真实材料计算分开。全程一次运行，不五帧试点。

## 时间与运动

两遍流式核XDATCAR完整帧、标签、严格步增，不隐式拼接重启。OSZICAR抽真实MD步/T/E、启动峰与早中晚块。全保存时间与可覆盖0–20ps分列不补尾；首保存时刻与持续跨度分开。最短像用倒空间界内完整整数像枚举，保存最大帧增量与采样充分条件。

并列原始、非Na等权平移、非Na质量平移、全原子等权参考；另全宿主刚体平移旋转拟合与残差，局部固定事件前6配体的平移/转动/形变分开。逐Na最终位移、r90、max、保存步路程与离起点>1Å后回到<0.5Å的离返；另1.5/1Å敏感性。位移不当路程、返回初始区域不当位点跳回。

继承1.5Å/200fs/直度≥0.7规则及重叠合并，阈值1.2/1.8Å并列；200fs事后单点标签和800fs反向抵消分列，不当真实跳跃。对照同Na全部事件（含当前）±200fs闭禁区，事件前/中/后完整相位不相交；不足明记。固定200fs与100/400fs前后中心、随访/首次返分列。

MSD首原点与多原点并列，完整、去2/4ps、固定4–14ps、后段独立起点，不挑有利窗。XLSX按精确cell和旧CSV逐口径对照，尾重复值保留并查来源；每lag记录原点数。拟合斜率/6、R²、alpha只为短窗诊断，不自动D资格，不算室温/电导/Ea。

## 环境、连接与空间

每保存帧Na/Cr/P的O、F和混合配位、距离/角度/径向畸变、配体atom+周期像、身份持续时间。初始实际距离间隙冻结短壳及±0.1Å，另Na3.2Å、Cr/P2.4Å与次级层，避免仅用自适应阈值。Cr/P固定初始配体ID刚体旋转角、非刚性残差、中心偏移、配体保持与新邻居；同CN不等单元稳定。

全时间每100fs及事件精帧保存真实周期边，分CrP共享、全部非Na中心/O/F二分图、Na共享配体与3.5/4Å距离图。共享顶点/棱/面由双方凸包及中心异侧核，不以共享数代几何。图rank非迁移维数。
