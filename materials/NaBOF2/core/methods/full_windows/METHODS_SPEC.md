# NaBOF2 本材方法

## 输入与已知差异

精确身份 `(NaBOF2, mp-1194338)`，原仓目录 `Oxyfluoride/52_NaBOF2_no-p-si-mp-1194338`。同式目录及其全部一级run有界枚举；当前已见 `aimd_1200K` 与 `relax`。后者INCAR的IBRION=2，无POTIM，不赋物理MD时间。CIF哈希与冻结清单完全一致。MD为Na48 B48 O48 F96，三斜定胞；XDATCAR胞仅6位小数，POSCAR更精细，胞比较容差1e-6Å，不复现历史过严cell断言错误。

只读复用已完成NaAl材料的分析函数，副本改为Na/B两类阳离子；Na48、B48、O48、F96全部保存帧按实际检查，不用NaAl数值。公共mech_core/both_outcomes只读复用1.5Å/200fs规则。旧O_II本材已有19.98ps完整分析及52缺POTIM失败保留；这次新增工作簿/MSD口径、启动/参考敏感性、全保存帧环境、候选参考漂移/转移及四节解释。

## 时间、运动和MSD

两遍流式核完整帧、configuration、POTIM/NBLOCK，核OSZICAR的实际MD step/T/E与重启。首保存帧不补成零时刻，真实全程与共同0–20ps实际覆盖分列。实际时间轴与MSD lag分开；并列首原点/多原点，raw、全部非Na等权/质量加权平移、全部原子平移及宿主刚体配准敏感性。保留full、剔2/4ps、绝对4ps起点、固定4–14ps及独立10/15ps后段起点。拟合斜率、R²/α只用于有限窗诊断，不给室温电导或Ea。

完整整数像枚举的最短像与展开，保存采样增量界。逐Na端点、r90、最大探索、保存帧路径长度、离>1Å后回<0.5Å及删失分开。候选事件净位移>=1.5Å/200fs且直度>=0.7，重叠并组；1.2/1.8Å敏感性。规则结局/A-B-C不叫真实跳跃；同Na全部事件±200fs闭禁区，完整前/中/后相位均排除，缺对照或固定200fs缺相位明确missing。固定事前6个O/F配体ID追踪平移/旋转/非刚性残差；100/200/400fs不互相补缺。

## O/F环境、连接、占据与空间

Na/B每保存帧分别O/F/混合配位、配体ID/周期像/键距角度和径向畸变。初始壳距离间隙及±0.1Å、固定Na3.2Å/B2.4Å、次级到3.5/3.0Å分开。B初始固定配体刚体拟合、配体保留与距离形变，区别转动、热涨落和重构。所有时间都做个体环境，周期几何边每100fs及事件精帧：B共享配体、完整非Na的B-O/F二分图、Na共享配体、Na距离3.5/4Å。共享1/2/3配体须双方凸包顶点/真棱/支持面及异侧核验，保留整数平移像；几何图秩不作输运维数。

以初始已占Na为有限参考，比较宿主平移与最近四B局部漂移参考；0.6/0.8/1.0Å指派、歧义、>=200fs停留、非自身区域进入/退出/下一去向。没有完整稳定位置全集，不报空位率。Na数密度与每Na体积互逆，不能当两份机制证据。12³分数网格、每0.5ps、对全部非Na统一排除1.2/1.5/1.8Å，保留周期6邻接及开放分数；这是指定几何探针，不是离子半径、能垒或真实Na体积分数。实际Na位置到宿主最近距离全帧保存。

B06只在充分初始结构身份下准备条件补偿模型（不弛豫/求能/新模拟），未建立元素优选不得强推荐。H01–H03另授权。所有科学结论UNVERIFIED，发表false。

## 运行与验证

新副本先合成RED（故意不展开PBC）/GREEN及三斜全像、索引、全事件禁区/完整相位、停留计时、宿主漂移/旋转/形变、同CN换配体、凸包伪棱/同侧面、周期图及多原点MSD反例。另核NaBOF2适配物种、单B中心、胞打印精度/IBRION与身份，不读取材料跑短试点。科学run只在测试真实完成后启动。
