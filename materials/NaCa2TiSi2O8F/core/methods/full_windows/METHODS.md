# 本材方法与边界

## 身份与时标

三条`Oxyfluoride/30...mp-1263670`、`42...mp-647450`、`43...mp-667200`各为独立结构/run，不合并。仅枚举这三目录及aimd_1200K/relax的一层文件；relax不算重复AIMD。保存原CIF、MD输入/轨迹/输出SHA；不读取POTCAR内容、不复制轨迹。绝对时间=XDATCAR标记步×实际POTIM/1000，不将首帧置零。全保存段、可用绝对0–20ps、4ps后、后半段分列；没有MD step0坐标不填。

## 运动与事件

复用已成`dynamics_core.py`的计数展开、倒格界完整最短像、展开、刚体拟合、固定窗与初始参考球纯函数；复用Na3Si3SnO9F/analysis_core.py的完整周期接触、事件与全相位同Na对照、周期图和几何函数。先读实现。原始、全非Na平均平移、全非Na刚体、固定局部配体参考分列；非刚性残差保留。20fs保存步内真实曲线未知，路程只为保存弦长和。

候选：任意200fs窗净位移≥1.5Å且净位移/保存步路程≥0.7；重叠或接触窗合并，合并净位移可以低于1.5Å。原运行对照在同Na同分析窗内排候选闭区间扩展±200fs；最终`CONTROL_GLOBAL_AUDIT.json`再映射至全轨迹帧，检查同Na全程所有事件禁区和前/主体/后完整相位。1018条中mp667200的after4ps Na12三条污染对照已排除，有效accepted_control=null；原control_dwell仍留史，不作最终有效比较。缺边界相位、缺随访、被排除且无替代对照均记null，不填0。固定100/200/400fs停留窗各自给值，另列200fs与最宽完整可用窗。规则事件、返回参考区域不称真实晶格跳跃。

## 环境、连接与空间

全部Na/Ca/Ti/Si分别记录O和F配位、固定初始间隙壳层及±0.1Å敏感性，另给固定距离短/次级接触；持久性按原子ID+周期像，不因边界包装改变配体身份。Na同帧运动与环境逐行对应；事件/对照三相位保存配体和局部参考诊断。强中心图只Ti/Si，完整非Na阳离子图另含Ca，Na共享配体与Na距离图另列；逐边保平移像。共享2/3配体需两侧凸包棱/面几何核；低维退化记不具识别性。图秩不作Na迁移维度或能垒。

参考占据仅以初始实际已占Na位置为参考球，半径0.6/0.8/1.0Å；没有全集，不报空位率或Frenkel浓度。访问过的候选区域用固定首次发现中心、1Å半径，只为访问分段，不称稳定格点。几何空间以全部非Na原子为等排除中心，16³周期网格、1.2/1.5/1.8Å排除距离及五个等间隔快照；此采样只用于空间代理，环境与运动均全帧。网格连边只邻格六方向，是几何代理而非势能路径。

## 输运与同式比较

分别输出首原点MSD、全时间原点MSD及原点数，拟合滞后0.2ps至min(10ps,半窗)和更后滞后区间。slope/6只作探索D(cm²/s)，不当稳态扩散资格；保负斜率/质量与末端单原点。工作簿按原单元格/目录身份比较，不凭重复配方图例映射。不同mp不自动独立重复，起始组成/晶胞/局部排列/算法参数均核对。
