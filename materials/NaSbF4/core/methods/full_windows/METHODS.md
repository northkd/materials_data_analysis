# NaSbF4：本次补充的定义

本方法用于当前一条1200 K轨迹，科学验收为UNVERIFIED。所有下述量的实际执行以 `runs/*/manifest.json` 和 `data/SCIENCE_RUN_RESULT.json` 为准，脚本准备不等于运行成功。

## 时间、MSD和个体运动

- 实际保存：MD步10、20、…15000，POTIM=2 fs、NBLOCK=10；第一保存帧绝对0.02 ps，最后30 ps。以第一保存帧为零时，完整0–29.98 ps；共同窗0–20 ps含1001帧。20 fs内未保存的路径未知。
- 图的底层工作簿 `F_114!A2:A26/C2:C26` 存1–25 ps滞后值。按说明丢弃200个保存帧，保留绝对4.02–30 ps的1300帧。曲线上的滞后时间Δt表示一对位置相隔多久，不是模拟绝对时刻；在Δt处平均1300−Δt/0.02对起点。图的“扣除平衡段后时间”容易混淆这两个含义，本文分开列。
- 首原点 MSD(Δt)=32个Na对某一窗口首帧的平方位移平均。全原点MSD再对窗口内全部合法起点平均。完整曲线、共同窗、弃4 ps、早0–9.98/中10–19.98/晚20–29.98/尾24–29.98 ps，全部平行保留；分段使用各段自己的起点，不增加温度或时长。
- 参照平行三种：原坐标；减去全部192原子的平均平移；减去160个非Na原子的平均平移。每段计算首原点和全原点，不选择有利口径。真实复现发现工作簿25点匹配raw多原点（最大差1.42e-14 Å²），不匹配其“全体原子残余漂移已扣”的说明（差0.319 Å²）；按实际口径解释。旧CSV10 ps与工作簿元信息不同；首原点精确匹配和拟合细节涉及后续未获执行的归约，最终解释不将拒绝后行读取的新增数值填入。原成功科学输出保留，历史口径不混用。
- 每Na端点、r90（到该窗口起点的距离的90%分位）、最大探索距离、20 fs折线路程、离返分别报告。离开为距离>1 Å，返回为随后<0.5 Å；返回对象是该段最初位置附近，非已证晶格位点。折线路程含振动与保存间隔影响，不是净输运长度。
- 科学运行已保存线性拟合斜率/6诊断，Å²/ps，含2–10 ps、中央20%–60%和末30%滞后区间及三参照。追加的归约/人工复核未完成，不作为本版已核D或R²结论。R²即便较高也不消除宿主重构、非平稳性、原点相关或单温短轨迹限制，不转成室温电导。

## 接触、周期和骨架

- 原件逐帧分数坐标展开：相邻保存帧缩回中心像后，笛卡尔增量小于晶胞最小奇异值的一半才能确认所选像最短。三斜晶胞不简单当正交；仍不能恢复20 fs之间的轨迹。
- 新补充的近邻搜索半径≤5 Å，逐分量周期缩回加严格倒易向量证书：R‖b_i‖<1/2，排除所有非中心像在此半径内的接触。独立Na/Sb/F原子索引保留0基，正文同时用Na#(1基)说明。
- 旧主接触层：每个Na/Sb按初始POSCAR距离间隙冻结半径，另保留±0.1 Å，未强制CN=6；本材Na约2.65 Å、Sb约2.89 Å，不同中心精确半径来自旧结果。Sb短程/次级固定2.4、2.7、3.0、3.3 Å分别统计。CN相同不等于配体身份相同。
- 新逐Na近邻：2.6/2.8/3.0 Å的Na–F CN、最近六个独立F原子ID（F6）、Jaccard集合相似度、最近Sb及该Sb的短程/次级F身份。J=交集/并集，完全相同为1、不相交为0。每个Na同一时刻对应，不用群体均值替代。
- 旧完整结构流301帧（100 fs+真实末帧），本次逐记录核减；Sb短程/次级精查1500帧（20 fs）接触身份再对原坐标核实。几何共享边/面沿用旧凸包核验，周期边保留中心a/b、晶格平移、共享F身份；仅共享两个/三个F不自动叫共棱/共面。强中心网络和全部非Na阳离子网络在本材均以Sb为节点、共享F为边；Na–F共享网络另列。图秩是几何网络跨胞方向数，不是Na传导维数。
- 宿主全局平移扣除不能去掉局部旋转和形变。刚性最小二乘使用固定ID原子，输出旋转角和拟合剩余RMS；局部环境已换配体时，固定六F刚性拟合只是参照敏感性，不能当稳定笼运动证据。长时间全宿主刚性对齐在周期重排后也只是诊断。

## 事件、对照、区域与空间

- 候选事件继承1.5 Å/200 fs，附1.2/1.8 Å敏感性。200 fs相隔位移过阈且直线度≥0.7；接近候选窗口合并，合并事件净位移可能回落。单点后随访距离标签、事件向量和与真实端点分别处理。A/B/C为旧规则，不是真跳跃/负例标签。
- 同Na对照排除这个Na全部候选事件的闭区间[起点−200fs,终点+200fs]；对照自身也必须带完整前后200 fs，且不触及任何闭禁区。先向前、再向后逐保存帧检查全部相位。复用对照不算独立样本。
- 固定200 fs前后均值距离、100/400 fs敏感性、事件终点是否已在前球、随后是否返回和右删失分别核；缺前/后窗口保missing，不用最宽窗填。实际导出每事件及合法对照从前200 fs至后200 fs的全部20 fs保存帧环境。
- 候选停留区域：对每个Na作互不重叠200 fs均值块，首访创建固定锚点，距已有锚点0.8/1.0/1.2 Å内分到最近者，记录进入/停留/离开/再访。它是单Na观察过的区域，不是全体Na共用位点全集，不能由区域个数算空位率或跨原子晶格交换；窗末短于200 fs块不填补。
- 旧初始已占Na参考球在0.6/0.8/1.0 Å下的空球、未分配、多占和歧义随时间保留；空球不同于结构空位。没有经可靠结构对应的完整可用位点全集，不报静态缺陷浓度、Frenkel形成率或反位真值。
- 几何开放空间复用旧61帧（500 fs+末帧）、周期网格15×22×23、轴向间距≤0.75 Å，宿主排除半径1.2/1.5/1.8 Å。开放比例/连通只反映到非Na原子距离；不含真实相互作用、Na互斥与自由能，不是离子体积分数或低势垒。
