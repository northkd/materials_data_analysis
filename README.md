## 数据与科学状态

- [清单与SHA256](MANIFEST.json)逐文件区分源SHA和公开副本SHA。JSON/CSV清理路径与身份元数据，科学数值、行/列与空值保持；PNG只移除文字/EXIF元数据，像素不变。
- [可用性说明](AVAILABILITY.md)列缺方法、摘要级材料与mp/时间窗例外。报告相对路径可能指向未公开附件，实际覆盖以各材ATTACHMENTS.csv为准。
- 公开内容为派生报告/表/PNG，未包含AIMD原件、NPZ/NPY、生产源码、受限表或私人运行历史。数据公开授权与科学接受、论文发表分开；科学状态仍为UNVERIFIED。
- 高温短轨迹不直接给出室温电导、稳定性、电子绝缘或器件资格。正文保留已支持/部分支持/不足/反例及真实删失条件。
